# snoredex-photos

The photograph archive of [snoredex-data](https://github.com/m4s-ai/snoredex-data): the original
images behind its specimen records.

## What is here

`verification/specimens/SPEC-nnnn.<png|jpg|jpeg>`: one original per specimen record, under the path
the records have always used. The register that describes each photograph is
[`verification/specimens.json`](https://github.com/m4s-ai/snoredex-data/blob/main/verification/specimens.json)
in snoredex-data: `photograph` names the file and `photographSha256` pins its bytes.

A file is added here and never changed or renamed. A corrected photograph gets a new specimen id.
